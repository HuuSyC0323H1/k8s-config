Đặc Điểm Nổi Bật

Được cấu hình tối ưu để phục vụ cả môi trường cục bộ và production / staging cluster.

🚀

Tối Ưu Tốc Độ

Trang web tĩnh thuần HTML5/CSS3/ES6 không phụ thuộc thư viện nặng nề, tải ngay tức thì.

📱

Chuẩn Responsive

Giao diện tương thích hoàn hảo trên mọi thiết bị: Desktop, Tablet, và Mobile.

🎨

Dark & Light Mode

Hỗ trợ chuyển đổi chủ đề màu sắc sáng/tối tự động lưu vào LocalStorage.

🐳

Sẵn Sàng Docker & K8s

Kèm sẵn Dockerfile và cấu hình Nginx Alpine siêu nhẹ (dưới 25MB) để deploy Kubernetes.

🔒

An Toàn & Ổn Định

Không có lỗ hổng backend động, bảo mật tối đa, dễ dàng cache qua CDN / Ingress.

⚙️

Dễ Dàng Tùy Biến

Cấu trúc thư mục sạch sẽ, mã nguồn tài liệu hóa rõ ràng, dễ dàng mở rộng theo yêu cầu.

Thông Số Kỹ Thuật

Cấu trúc công nghệ sử dụng trong gói static web này

Front-end

Giao Diện & Script

  • Ngôn ngữ: HTML5, Semantic Elements
  • Định kiểu: Modern CSS3 (Variables, Flexbox, Grid)
  • Font chữ: Plus Jakarta Sans
  • Tương tác: Vanilla JavaScript (Zero Dependencies)
Deployment

Triển Khai & Container

  • Web Server: Nginx Alpine (nếu chạy Docker)
  • Môi trường: STG (Staging)
  • Cổng mặc định: 80 (HTTP)
  • Khả năng scale: Horizontal Pod Autoscaler (HPA)
